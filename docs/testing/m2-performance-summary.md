## 已接受的剩余性能工作

- 百万行内存和批量检索尚未完全追平 2.5.1；现有差距保留，不以近似距离、删校验或弱化 fsync 消除。
- 大规模 VARCHAR、失效位密度、活跃 WAL 与 segment 混合布局、写入并发、大 limit/输出、其他维度与度量，尚无上述专项的同等性能证据。
- 桌面负载未隔离，有限样本不构成稳定 p99 保证。各轮的原始记录与失败/无收益诊断保留在仓库外。
- Windows、真实断电和首次发布验收仍分别按其合同推进；当前源码没有因为阶段总结再运行全部历史矩阵。

后续若发现实际负载的瓶颈，再以同机同数据、2.5.1/3.x/上一版本对照立专项。本阶段不增加新的并发调度、过滤索引、表达式缓存或通用内存框架。

### 对两项偏高结果的补采样

主矩阵中，百万行整数过滤的 N5/A 三轮值分别为 `[4.21,3.33,3.87]` / `[4.26,3.02,3.21]` ms，中位数比为 1.206；nq100 分别为 `[267.06,190.85,206.34]` / `[270.51,182.97,187.17]` ms，中位数比为 1.102。轮间区间重叠，不能据此直接归因为 B 代码，也不能只略去偏高值。

多桶比 N5 普通模式约高 6.6%；该工作负载下 N5 整进程峰值仍高于 3.x。实现缓冲随本请求行数 / 列宽 / 实际桶数增长，不复制全库主键或向量；这不等于承诺峰值低于参照。C++ 为外部子进程，未用该进程内峰值与 C++ 内存比较；上表冷恢复 RSS 才使用各自服务进程范围。正式发布平台与实际断电保证仍按 0013 / 0007，不从这组本机性能推导。

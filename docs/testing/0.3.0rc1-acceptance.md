## 格式、恢复及新增能力

各平台安装后核对实际解释器、SDK、包版本与 native SHA256；正式和 FI 环境分开核验。所有正式 wheel 的 Python 文件与冻结包源码相同，长描述与冻结 README 一致。Linux 的 ELF / GLIBC 检查及两 Mac 的架构 / 最低部署字段检查均通过。

Linux 两架构分别执行双向 LOCK、原始 strace 与提交顺序分析；原始跟踪及检查结果归档。两套 PID 1 normal / drain / kill 均通过，退出码为 0 / 0 / 137，确认行和值及 `_seq` 重开核验通过，不把 keepalive 容器退出当成产品 PID 1 结果。x86 PID 1 的可信编排容器使用 Docker socket 与 host 网络，被测镜像按冻结 Dockerfile 以 tester UID 1000 运行；常规标准层分别为非 root UID 501 / 1145。

从本次正式 wheel 执行分区、key、非 key Upsert、nullable / ARRAY、Query iterator、range / V1 的联合生命周期。V2 原样探针在四个平台确认普通 Search code 0、ID `[0,1]`、无 V2 结果字段，SDK 回退 `SearchIterator`；x86 使用已验收的 Python 3.10 / SDK 3.0.2，其余为 3.15 / SDK 3.0.2。

旧读者先按保留的已发布 SHA256SUMS 验证 wheel，再在独立环境安装：key 的 wal / segment / compacted × 四个旧版本 12 项，nullable / defaults / ARRAY 的三种状态 × rc1–rc3 9 项，显式分区 wal / segment × 0.2.0rc1 2 项，共 23 项通过。覆盖新属性 / 非默认分区拒绝、受保护文件不变、健康 collection 可读及 Drop 最后非默认分区后默认数据 / 全局删除可读。种子和旧读者副本分开，不触碰发布前的原始用户目录。

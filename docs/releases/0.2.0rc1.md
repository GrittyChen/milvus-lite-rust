# 0.2.0rc1 发行范围与说明

本文固定本版本的功能范围、限制与安装说明，作为 GitHub Release 正文的内容来源，不记录随发布推进变化的状态。冻结提交、附件哈希和执行结果由对应 GitHub Release 正文链接的候选验收记录给出；是否已发布及公开下载结果以该正文为准。

这是以 Rust 实现的非官方 milvus-lite，与 Milvus／Zilliz 无隶属关系。该版本为预发布试用，不建议用于生产；RC 阶段通过本项目 GitHub Release 分发，不上传 PyPI。以下安装入口须等对应 Release 正式发布后使用。

## 相对 0.1.0rc3 的功能增量

- 标量 nullable 与默认值：BOOL、INT8/16/32/64、FLOAT/DOUBLE、VARCHAR、JSON；Insert／Upsert、过滤、输出及恢复一并支持。主键 nullable 按参照拒绝，向量 nullable 延后。
- ARRAY：BOOL、INT8/16/32/64、FLOAT/DOUBLE、VARCHAR 元素，包含父列 null、容量校验、数组函数与下标访问。JSON、嵌套数组和向量元素不支持。存量元素 null 可保留，但经 gRPC 投影时报错，与参照一致。
- Query iterator：接通 SDK 的主键续读，支持 INT64／VARCHAR 排序和既有过滤／投影；每个请求使用独立快照，不承诺跨请求快照一致。
- Range search 与 SDK Search iterator V1：支持 L2／IP／COSINE 的 radius／range_filter、offset、多查询和输出字段。范围判断发生在有限候选窗口内，窗口沿用参照 3.x 的行为，不是全量范围扫描。

实现合同与边界见 [0015](../decisions/0015-nullable-defaults-and-array.md)、[0016](../decisions/0016-query-iteration-and-range-search.md)。参照固定为官方 milvus-lite v3.2.1／`43d1257774e629bc9f66873977ab7c320d5bf5a7`。

## 兼容性与已知限制

- 沿用 3.x 的 schema.json、Arrow IPC WAL 与 Parquet 编码，不增加私有数据格式。旧能力目录继续支持；旧 rc1–rc3 会明确拒绝包含新 schema 属性的 collection，不能将新目录可回退理解为旧版能读取新增类型。
- 过滤继续按参照的整条表达式路线执行，缺失值、null、短路及类型错误依路线而异。算术、时间与几何谓词仍为范围外。
- JSON 顶层标量及相应默认值沿用 0004 已登记的任意 JSON 值规则，存在参照 Arrow 转换缺陷对应的差异；非有限数值与 binary 原始默认值暂不支持，超出参照默认数字位数限制的数值也明确拒绝，具体边界见 0015。
- 距离沿用 [0004](../decisions/0004-m1-scope.md) 的浮点误差预算；范围阈值落在误差带内时，两端可能有成员或数量差异。服务端仍作严格比较，不加 epsilon；带外结果不得以该规则豁免。
- Search iterator V1 依赖 SDK 的有限探测算法，部分批量和距离分布下会提前结束；不保证任意数据下完整遍历。服务端 V2、token 和跨请求 MVCC 未实现。
- 手写 proto 中，被同名后列覆盖或被完整布局 valid_data 掩码遮住的坏 JSON 仍会被拒绝；相对 rc3 的严格化边界及理由见 [0015](../decisions/0015-nullable-defaults-and-array.md)。普通 SDK 不构造这类请求。
- 两条 SDK 的端点 schema 缓存限制仍存在：同一进程中，显式释放后复用端口，或 CLI 在固定端口更换数据目录重启，可能使 SDK 沿用旧 schema。此问题在真实 3.x 上也存在；测试的跨用例隔离没有修改 SDK 或产品运行行为，见[调查与反证](../testing/0015-0016-cross-platform-acceptance.md#本轮发现两条-sdk-的跨用例-schema-缓存污染)。
- 向量仍仅以 FLAT 执行，已接受的 ANN 定义不意味着实际 ANN；新建 INVERTED 只接受 BOOL、INT8/16/32/64、FLOAT/DOUBLE、VARCHAR，执行仍为扫描；JSON／ARRAY 新定义被拒绝，存量 ARRAY 定义在需要构建时按参照报错。存量定义、DropIndex 及持久化未确认时的封锁／恢复沿用 [0014](../decisions/0014-index-definitions-and-filter-expressions.md) 和 [README](../../README.md)。
- 分区、alias／rename、稀疏向量、BM25／function chain、nullable 向量、真实 ANN、TIMESTAMPTZ／GEOMETRY、AddCollectionField／AlterCollectionSchema 不进入本次范围。

## 平台、解释器与证据边界

沿用 [0013](../decisions/0013-first-release-platform-and-packaging.md)：Linux x86_64／arm64 的 glibc 2.28，macOS arm64 最低版本字段为 11.0；macOS x86_64 只要求构建与两个解释器端点的冒烟，实际原生或 Rosetta 方式须在最终验收中注明。GIL CPython 验证窗口为 3.10–3.15，两条 SDK 固定为 pymilvus 2.6.17／3.0.2。

Windows、free-threaded 和非 CPython 在构建时明确拒绝。musl、其它架构及较低 glibc 的自行构建仅为实验性尝试；容器运行和二进制系统下限字段不等于真机最低系统、真实断电或任意文件系统持久化证明。

[开发跨平台验收](../testing/0015-0016-cross-platform-acceptance.md)已经复审通过；版本候选须另从最终提交构建并按 0013 验收，开发结果不替代最终产物的证据。最终附件为四个平台的正式 wheel、sdist 与覆盖这些附件的 SHA256SUMS；FI wheel 仅供隔离验收，不随发行分发。

## 安装（对应 Release 发布后）

本包与官方 milvus-lite 共用 `milvus_lite` 模块，不可同时安装；不用 `pymilvus[milvus-lite]`。

```bash
python -m pip uninstall milvus-lite
python -m pip install pymilvus
python -m pip install --no-index --only-binary :all: --find-links https://github.com/GrittyChen/milvus-lite-rust/releases/expanded_assets/v0.2.0rc1 milvus-lite-rust==0.2.0rc1
```

也可从 [v0.2.0rc1 Release](https://github.com/GrittyChen/milvus-lite-rust/releases/tag/v0.2.0rc1) 下载本平台 wheel 与 SHA256SUMS，核对后安装：

```bash
shasum -a 256 -c --ignore-missing SHA256SUMS && python -m pip install --no-index ./milvus_lite_rust-0.2.0rc1-*.whl
```

Linux 可用 sha256sum 执行同样的校验。sdist 的 Python 下限及 Rust 1.89 MSRV 沿用 [源码回退门槛](../../tests/packaging/README.md#源码与拒绝门槛)，不引导从 PyPI 按项目名解析本包。
